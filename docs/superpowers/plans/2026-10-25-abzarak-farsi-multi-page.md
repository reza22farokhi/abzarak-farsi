# برنامه اجرایی توسعه ابزارک فارسی

## مرحله ۱: بررسی و پشتیبان‌گیری
- بررسی Git و فایل‌های موجود
- نگهداری نسخه پشتیبان
- بررسی کد فعلی و وابستگی‌ها

## مرحله ۲: قالب مشترک
- ایجاد assets/css/styles.css
- ایجاد assets/js/common.js
- تبدیل index.html به صفحه اصلی ابزارها
- بررسی ظاهر و لینک‌ها

## مرحله ۳: ابزارهای محاسباتی
- محاسبه درصد
- محاسبه تخفیف
- محاسبه سود
- اعتبارسنجی ورودی‌ها و آزمایش محاسبات

## مرحله ۴: ابزارهای متن
- شمارش کلمات، نویسه‌ها و خطوط
- پاک‌سازی نویسه‌های رایج فارسی
- آزمایش متن خالی، نیم‌فاصله و متن چندخطی

## مرحله ۵: رمز عبور و QR
- انتقال تولید رمز به فایل مستقل
- حفظ تولید امن رمز با Web Crypto
- مدیریت خطاهای کتابخانه QR و اتصال اینترنت

## مرحله ۶: ابزارهای توسعه‌دهندگان
- قالب‌بندی و اعتبارسنجی JSON
- تبدیل Base64 با پشتیبانی از UTF-8
- انتخاب رنگ و نمایش HEX

## مرحله ۷: سئو
- عنوان و توضیح متای اختصاصی صفحات
- ایجاد sitemap.xml
- ایجاد robots.txt
- بررسی لینک‌های داخلی

## مرحله ۸: انتشار
- اجرای git diff --check
- بررسی تغییرات و فایل‌های پشتیبان
- commit فقط فایل‌های موردنظر
- push به GitHub
- بررسی HTTP 200 برای تمام صفحات
