# طرح توسعه چندصفحه‌ای ابزارک فارسی

## هدف
تبدیل سایت فعلی به صفحه اصلی و صفحات مستقل ابزارها، با حفظ
آدرس فعلی، طراحی واکنش‌گرا، زبان فارسی و میزبانی رایگان.

## ابزارها
1. محاسبه درصد
2. محاسبه تخفیف
3. محاسبه سود
4. شمارش متن
5. پاک‌سازی متن فارسی
6. تولید رمز عبور
7. ساخت QR Code
8. قالب‌بندی JSON
9. تبدیل Base64
10. انتخاب رنگ

## معماری
- HTML، CSS و JavaScript ساده
- استایل مشترک در assets/css/styles.css
- کد مشترک در assets/js/common.js
- صفحات مستقل ابزارها در tools/
- حفظ صفحه اصلی و آدرس فعلی GitHub Pages
- عدم نیاز به سرویس پولی یا چارچوب سنگین

## معیارهای پذیرش
- حفظ RTL و سازگاری با موبایل
- عملکرد صحیح ابزارها و اعتبارسنجی ورودی‌ها
- مدیریت خطاهای JSON، Base64 و QR Code
- عنوان و توضیح متای اختصاصی برای هر صفحه
- ایجاد sitemap.xml و robots.txt
- تهیه نسخه پشتیبان قبل از تغییر
- آزمایش تمام صفحات پیش از انتشار
- عدم افزودن فایل‌های پشتیبان به commit
