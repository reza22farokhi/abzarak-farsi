آموزش کامل Termux از صفر تا صد

دسته: برنامه‌نویسی موبایل | زمان مطالعه: ۱۵ دقیقه | به‌روزرسانی: آبان ۱۴۰۵

Termux یکی از شگفت‌انگیزترین اپلیکیشن‌های اندروید است که یک محیط کامل لینوکس را درون گوشی شما شبیه‌سازی می‌کند. با Termux می‌توانید پایتون، Node.js، Git، PHP، کامپایلر C/C++ و صدها ابزار دیگر را روی گوشی خود اجرا کنید، بدون اینکه نیاز به کامپیوتر داشته باشید.

در این مقاله جامع، از نصب Termux تا اجرای پروژه‌های واقعی را گام به گام یاد می‌گیرید. اگر می‌خواهید گوشی اندرویدی خود را به یک ایستگاه کاری کامل تبدیل کنید، این مقاله دقیقاً برای شماست.

می‌خواهید همه دستورات Termux را یک‌جا داشته باشید؟

ما یک مرجع کامل از ۳۲۰+ دستور Termux با توضیح فارسی، دسته‌بندی شده و قابل جستجو ساخته‌ایم.

💻 مشاهده ۳۲۰+ دستور Termux

Termux دقیقاً چیست؟

Termux یک شبیه‌ساز ترمینال (Terminal Emulator) و محیط لینوکس برای اندروید است که بدون نیاز به Root کار می‌کند. برخلاف اپلیکیشن‌های معمولی، Termux به شما دسترسی به یک محیط شبیه Ubuntu/Debian می‌دهد که در آن می‌توانید:

  • 🐍 کد پایتون، Node.js، PHP، Ruby یا Go بنویسید و اجرا کنید
  • 📦 با Git به GitHub متصل شوید و پروژه‌هایتان را مدیریت کنید
  • 🌐 سرور محلی HTTP اجرا کنید و سایت خود را تست کنید
  • 🔐 از ابزارهای امنیتی مثل OpenSSL و SSH استفاده کنید
  • 🎬 با ffmpeg ویدیو تبدیل کنید
  • 📥 با youtube-dl ویدیو دانلود کنید
  • ⚡ از طریق Termux API به دوربین، GPS، باتری، کلیپ‌بورد و سایر سنسورهای گوشی دسترسی داشته باشید

به زبان ساده: Termux یک لپ‌تاپ لینوکسی داخل گوشی شماست.

چرا باید از Termux استفاده کنید؟

شاید بپرسید چرا کسی باید در گوشی‌اش برنامه‌نویسی کند؟ دلایل زیادی وجود دارد:

۱. یادگیری لینوکس و دستورات آن

اگر می‌خواهید لینوکس یاد بگیرید اما کامپیوتر یا هاست لینوکسی ندارید، Termux بهترین کلاس آموزشی رایگان است. تمام دستوراتی که یاد می‌گیرید، روی سرورهای واقعی هم کار می‌کنند.

۲. توسعه در هر مکان

وقتی در مترو، اتوبوس یا کافه هستید و ایده‌ای به ذهنتان می‌رسد، با Termux می‌توانید بلافاصله کد بزنید، تست کنید و در GitHub پوش کنید. دیگر نیازی نیست منتظر رسیدن به کامپیوتر باشید.

۳. سرور موقت

می‌توانید یک سرور HTTP راه بیندازید و فایل‌هایتان را در شبکه محلی به اشتراک بگذارید، یا حتی یک API شخصی بسازید.

۴. رایگان و بدون Root

برخلاف بسیاری از ابزارها، Termux نیازی به روت کردن گوشی ندارد و در Google Play یا F-Droid رایگان در دسترس است. امنیت گوشی شما حفظ می‌شود.

۵. قدرت در جیب شما

گوشی‌های امروزی از بسیاری از لپ‌تاپ‌های ۱۰ سال پیش قوی‌ترند. با Termux می‌توانید از این قدرت واقعی استفاده کنید.

نصب Termux (گام به گام)

روش اول: از F-Droid (پیشنهاد ما)

Termux را از F-Droid نصب کنید، نه Google Play. نسخه Google Play منسوخ شده و به‌روزرسانی نمی‌شود.

  1. سایت f-droid.org را باز کنید و اپلیکیشن F-Droid را نصب کنید.
  2. در F-Droid، عبارت "Termux" را جستجو کنید.
  3. روی دکمه نصب بزنید و منتظر بمانید.

روش دوم: از GitHub (برای نسخه‌های جدید)

نسخه‌های Nightly و آخرین نسخه‌ها را می‌توانید از مخزن GitHub پروژه Termux دانلود کنید.

روش سوم: از Google Play (توصیه نمی‌شود)

نسخه Google Play قدیمی و بدون پشتیبانی است. حتماً از F-Droid یا GitHub استفاده کنید.

تنظیمات اولیه پس از نصب

پس از باز کردن Termux، این دستورات را به ترتیب اجرا کنید:

۱. به‌روزرسانی مخازن

pkg update && pkg upgrade -y

این دستور، لیست پکیج‌ها را به‌روزرسانی و پکیج‌های نصب‌شده را ارتقا می‌دهد. ممکن است چند دقیقه طول بکشد.

۲. دسترسی به حافظه گوشی

termux-setup-storage

پس از اجرای این دستور، یک پنجره مجوز ظاهر می‌شود. باید اجازه دسترسی به حافظه را بدهید. سپس پوشه‌ای به نام storage در home شما ساخته می‌شود که به پوشه‌های گوشی (Downloads، Pictures، DCIM و...) دسترسی دارد.

۳. نصب پکیج‌های ضروری

pkg install git python nodejs nano curl wget -y

این دستور Git، Python، Node.js و ابزارهای پایه را نصب می‌کند.

۴. تنظیم مخزن (اگر دانلود کند بود)

termux-change-repo

اگر سرعت دانلود پکیج‌ها پایین است، این دستور را اجرا کنید و یک mirror دیگر انتخاب کنید (مثلاً Grimler یا AER).

نیاز به مرجع دستورات دارید؟

۳۲۰+ دستور Termux در ۲۰ دسته‌بندی، با توضیح فارسی و قابلیت کپی سریع.

📚 ورود به مرجع دستورات

۲۰ دستور ضروری که هر کاربر Termux باید بداند

در اینجا مهم‌ترین دستوراتی که هر روز به کارتان می‌آید را معرفی می‌کنیم. (لیست کامل ۳۲۰+ دستور در مرجع دستورات Termux ما موجود است).

مدیریت پکیج‌ها

pkg install [package]
pkg uninstall [package]
pkg list-installed
pkg search [name]

مدیریت فایل‌ها

ls -la       # نمایش فایل‌ها با جزئیات
cd [dir]     # ورود به پوشه
mkdir [name] # ساخت پوشه
cp [src] [dest] # کپی
mv [src] [dest] # انتقال
rm -rf [dir] # حذف پوشه (احتیاط!)

شبکه

ping google.com   # تست اتصال
curl [url]        # دریافت محتوا
ssh user@host     # اتصال به سرور

برنامه‌نویسی

python            # ورود به محیط پایتون
python3 -m http.server 8000  # سرور HTTP
git clone [url]   # دریافت پروژه

۳ سناریوی واقعی و کاربردی

سناریو ۱: ساخت وب‌سایت شخصی روی گوشی

یکی از قدرتمندترین کاربردهای Termux، ساخت و میزبانی یک وب‌سایت کامل است. برای مثال، همین سایت ابزارک فارسی که در حال خواندن آن هستید، با کمک Termux و Git ساخته شده است! در ادامه، مراحل ساخت یک سایت ساده را می‌بینید:

mkdir mysite
cd mysite
nano index.html
# کد HTML خود را بنویسید و ذخیره کنید (Ctrl+O, Enter, Ctrl+X)
python3 -m http.server 8000

حالا در مرورگر گوشی، آدرس http://localhost:8000 را باز کنید. سایت شما آماده است! برای انتشار در اینترنت، فقط کافی است یک مخزن GitHub بسازید و با git push محتویات را آپلود کنید.

سناریو ۲: یادگیری پایتون در هر زمان

python
>>> print("سلام دنیا!")
>>> 2 + 3
5

برای اجرای یک اسکریپت پایتون:

nano test.py
# کد را بنویسید
python test.py

سناریو ۳: دانلود ویدیو از یوتیوب

pkg install python -y
pip install yt-dlp
yt-dlp "https://youtube.com/watch?v=VIDEO_ID"

فایل ویدیو در همان پوشه ذخیره می‌شود. برای دسترسی به حافظه گوشی، از مسیر ~/storage/downloads استفاده کنید.

Termux API: قدرت گوشی در دست شما

یکی از فوق‌العاده‌ترین ویژگی‌های Termux، افزونه Termux API است که به شما اجازه می‌دهد به سنسورهای گوشی دسترسی داشته باشید. برای استفاده:

  1. اپلیکیشن Termux:API را از F-Droid نصب کنید.
  2. در ترمینال: pkg install termux-api -y

حالا این دستورات جادویی را امتحان کنید:

termux-battery-status     # وضعیت باتری
termux-location           # موقعیت GPS
termux-toast "سلام!"      # نمایش پیام روی صفحه
termux-vibrate -d 1000    # ویبره ۱ ثانیه
termux-clipboard-set "متن"  # کپی به کلیپ‌بورد
termux-camera-photo photo.jpg  # گرفتن عکس
termux-sms-list           # لیست پیامک‌ها

با این APIها می‌توانید اسکریپت‌های فوق‌العاده بسازید؛ مثلاً اسکریپتی که وقتی باتری به ۲۰٪ رسید، به شما نوتیفیکیشن بدهد.

ترفندهای حرفه‌ای

۱. استفاده از tmux برای مدیریت session

اگر یک پروژه طولانی دارید و می‌خواهید ترمینال را ببندید اما اسکریپت شما در پس‌زمینه اجرا شود، از tmux استفاده کنید:

pkg install tmux -y
tmux new -s mysession
# کار خود را انجام دهید، سپس Ctrl+B و بعد D برای خروج
tmux attach -t mysession  # بازگشت به session

۲. جلوگیری از خواب گوشی

termux-wake-lock

وقتی اسکریپت طولانی اجرا می‌کنید، این دستور مانع از این می‌شود که گوشی به حالت خواب برود و اسکریپت متوقف شود.

۳. استفاده از شل مدرن (zsh)

pkg install zsh -y
chsh -s zsh

zsh با auto-complete هوشمند و theme‌های زیبا تجربه ترمینال شما را متحول می‌کند.

۴. میانبرهای سفارشی

فایل ~/.bashrc را باز کنید و میانبرهای خودتان را بسازید:

nano ~/.bashrc
# اضافه کنید:
alias ll='ls -la'
alias update='pkg update && pkg upgrade -y'
alias gs='git status'

اشتباهات رایج مبتدیان

  • ❌ نصب از Google Play: نسخه قدیمی است. حتماً از F-Droid نصب کنید.
  • ❌ اجرای دستورات نامفهوم از اینترنت: هرگز دستورات curl ... | bash را از منابع ناشناس اجرا نکنید. ممکن است به گوشی شما آسیب بزنند.
  • ❌ فراموش کردن pkg update: قبل از نصب هر پکیج، لیست پکیج‌ها را به‌روز کنید.
  • ❌ استفاده از rm -rf بدون احتیاط: این دستور می‌تواند تمام فایل‌های شما را پاک کند. همیشه مسیر را دوبار بررسی کنید.
  • ❌ انتظار اجرای GUI: Termux فقط ترمینال است. برای برنامه‌های گرافیکی به Termux:X11 نیاز دارید.

Termux بهترین گزینه برای کسانی است که می‌خواهند یک محیط ترمینال سبک، سریع و رایگان داشته باشند.

خلاصه‌ی این مقاله در ۵ خط

  1. Termux یک محیط لینوکس کامل و رایگان روی اندروید است که نیاز به Root ندارد.
  2. از F-Droid نصب کنید، نه Google Play. سپس با pkg update && pkg upgrade شروع کنید.
  3. با termux-setup-storage به حافظه گوشی دسترسی بگیرید و پکیج‌های ضروری را نصب کنید.
  4. می‌توانید سایت بسازید، پایتون اجرا کنید، ویدیو دانلود کنید و حتی به سنسورهای گوشی دسترسی داشته باشید.
  5. با تسلط بر ۲۰ دستور ضروری و یادگیری ترفندهای حرفه‌ای، گوشی شما به یک ایستگاه کاری کامل تبدیل می‌شود.
