راهنمای جامع ساخت وب‌سایت شخصی رایگان (بدون هاست و دامنه)

دسته: توسعه وب | زمان مطالعه: ۱۰ دقیقه | به‌روزرسانی: آبان ۱۴۰۵

سال‌ها پیش، اگر می‌خواستید یک وب‌سایت شخصی داشته باشید، باید هزینه‌های سنگینی برای خرید هاست و دامنه می‌پرداختید و یا با پیچیدگی‌های راه‌اندازی سرور دست و پنجه نرم می‌کردید. اما امروزه با ظهور سرویس‌هایی مثل GitHub Pages، شما می‌توانید یک وب‌سایت کاملاً حرفه‌ای، سریع و امن را به صورت ۱۰۰٪ رایگان راه‌اندازی کنید.

در این مقاله، دقیقاً همان مسیری را به شما آموزش می‌دهم که خودم برای ساخت سایت «ابزارک فارسی» طی کردم. سایتی که امروز بیش از ۳۸ ابزار و ۲۵ مقاله دارد و حتی به یک اپلیکیشن اندروید تبدیل شده است.

می‌خواهید سایت خود را به اپلیکیشن تبدیل کنید؟

پس از ساخت سایت، با ابزار رایگان ما بررسی کنید که آیا سایت شما آماده تبدیل به اپلیکیشن اندروید است یا نه.

🔍 آنالیزور PWA

چرا GitHub Pages بهترین انتخاب برای شروع است؟

  • کاملاً رایگان: برای همیشه، بدون نیاز به کارت اعتباری.
  • سرعت بالا: سایت‌ها روی سرورهای قدرتمند CDN گیت‌هاب (Fastly) میزبانی می‌شوند.
  • امنیت کامل (HTTPS): گواهی SSL به صورت خودکار برای شما صادر می‌شود.
  • کنترل نسخه (Git): تمام تغییرات سایت شما ذخیره می‌شوند و در صورت اشتباه می‌توانید به عقب برگردید.

مرحله ۱: ساخت حساب کاربری در GitHub

اولین قدم، ساخت یک اکانت رایگان در GitHub.com است. پس از ثبت‌نام، شما یک پروفایل خواهید داشت که می‌تواند به عنوان سایت شخصی شما هم عمل کند.

مرحله ۲: ساخت مخزن (Repository) مناسب

برای اینکه سایت شما در ریشه دامنه‌ی گیت‌هاب قرار بگیرد (مثلاً `username.github.io`)، باید یک مخزن با نام کاربری خودتان بسازید:

  1. روی دکمه New repository کلیک کنید.
  2. در قسمت Repository name، دقیقاً نام کاربری خود را بنویسید و در انتها .github.io اضافه کنید. (مثلاً اگر نام کاربری شما `ali` است، نام مخزن باید `ali.github.io` باشد).
  3. گزینه Public را انتخاب کنید.
  4. تیک Add a README file را بزنید و روی Create repository کلیک کنید.

مرحله ۳: ساخت فایل‌های سایت

حالا که مخزن ساخته شد، باید فایل‌های سایت خود را بسازید. ساده‌ترین راه، استفاده از یک فایل index.html است.

در مخزن خود، روی دکمه Add file > Create new file کلیک کنید. نام فایل را index.html بگذارید و کد زیر را در آن قرار دهید:

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>سایت شخصی من</title>
</head>
<body>
  <h1>سلام دنیا! به سایت من خوش آمدید.</h1>
</body>
</html>

مرحله ۴: فعال‌سازی GitHub Pages

تنها کاری که برای آنلاین شدن سایت باقی مانده، فعال کردن GitHub Pages است:

  1. در صفحه مخزن، به تب Settings بروید.
  2. از منوی سمت چپ، روی Pages کلیک کنید.
  3. در بخش Build and deployment، در قسمت Source، گزینه Deploy from a branch را انتخاب کنید.
  4. در قسمت Branch، شاخه main و پوشه / (root) را انتخاب و روی Save کلیک کنید.

پس از ۱ تا ۲ دقیقه، آدرسی مثل https://username.github.io بالا می‌آید و سایت شما آنلاین می‌شود!

مرحله ۵: استفاده از قالب‌های آماده (بدون کدنویسی)

اگر با HTML و CSS آشنا نیستید، نگران نباشید. می‌توانید از قالب‌های آماده Jekyll استفاده کنید یا از سایت‌هایی مثل GitHub Pages Themes یک قالب انتخاب کنید و تنظیمات آن را در فایل _config.yml وارد کنید.

مرحله ۶: توسعه سایت با موبایل (اختیاری)

شاید باورتان نشود، اما من کل سایت «ابزارک» را با موبایل و برنامه Termux ساختم. Termux یک محیط لینوکس کامل روی اندروید است که به شما اجازه می‌دهد کد بزنید و با گیت (Git) فایل‌ها را آپلود کنید. اگر به این کار علاقه‌مند شدید، حتماً سری به مرجع دستورات Termux ما بزنید.

می‌خواهید یک دامنه اختصاصی داشته باشید؟

وقتی سایتتان آماده شد، می‌توانید یک دامنه مثل .ir یا .com بخرید و به آن متصل کنید.

راهنمای خرید و اتصال دامنه

مرحله ۷: قدم‌های بعدی (حرفه‌ای شدن)

ساخت سایت فقط شروع ماجراست. برای اینکه سایتتان دیده شود، باید این مراحل را انجام دهید:

  • سئو (SEO): با مطالعه مقاله چطور در گوگل رتبه یک شویم، سایت خود را برای موتورهای جستجو بهینه کنید.
  • تبدیل به اپلیکیشن: با استفاده از مقاله تبدیل سایت به اپلیکیشن، یک اپ اندروید از سایت خود بسازید.
  • افزودن ابزارهای کاربردی: می‌توانید از ابزارهای آماده استفاده کنید یا کدهای آن‌ها را از سایت ما الگو بگیرید.

مشکلات رایج و راه‌حل‌ها

  • ❌ سایت من بالا نمی‌آید (خطای 404): مطمئن شوید که فایل index.html در ریشه (root) مخزن قرار دارد. همچنین ممکن است نیاز به چند دقیقه صبر داشته باشید.
  • ❌ تصاویر یا فایل‌های CSS لود نمی‌شوند: مسیر فایل‌ها را چک کنید. در گیت‌هاب، به بزرگی و کوچکی حروف (Case Sensitivity) بسیار حساس است.
  • ❌ سایت به روز نمی‌شود: کش مرورگر خود را پاک کنید (Ctrl + F5) یا از تب ناشناس استفاده کنید.

💡 جمع‌بندی: ساخت یک وب‌سایت رایگان با GitHub Pages بهترین راه برای شروع است. شما با صفر هزینه می‌توانید یک پورتفولیو حرفه‌ای، وبلاگ شخصی یا حتی مجموعه ابزارهای آنلاین (مثل ابزارک) داشته باشید. کافیست امروز اولین قدم را بردارید.
